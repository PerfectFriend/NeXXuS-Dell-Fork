# FIRST CONTACT — первый живой линк между двумя физически разными нодами

**2026-11-24, ~17:30 CET.** Впервые в истории проекта две физически разные
машины увидели друг друга и подружились по нашему протоколу.

## Участники

| | нода A | нода B |
|---|---|---|
| хост | `castle` (192.168.58.191) | второй Ubuntu-хост (192.168.58.1) |
| node_id | `b9f17399565a9d38ffb45106d1a309fd3d272d34554ed9c2a67ec0cd20fc0ad7` | `0ce668d42f961a5eabc1d4de13875cdc00351d257f75c6b297b1767c114c5713` |

## Транспорт
LAN, прямой TCP `192.168.58.1:4001` (wire v3). Tor/Tailscale в этом эпизоде не участвовали.

## Что прошло вживую (проверено, не задекларировано)
1. `Ping` без handshake → нода B ответила `ErrorResponse 0xFF "unknown peer: send NodeAnnounce first"` — протокол узнан.
2. `p2p_client` (пример из `crates/nexxus-core/examples/p2p_client.rs`): полный **NodeAnnounce handshake с взаимной проверкой Ed25519-подписей** → peer node_id подтверждён.
3. `Ping → Pong` (подписан пиром).
4. `StoreChunk` 64 KiБ → `StoreChunkAck`, hash `82ced14f0c77f9f685d3b0efe4de53f95d6a02298de9a742145738b888352203`.
5. `FetchChunk` → `FetchChunkResp`, 65536 байт **сошлись бит-в-бит** — данные реально ушли на другую машину и вернулись.
6. Нода A внесла B в постоянные пиры: `node_connect 192.168.58.1:4001` → `node_peers` показывает `outbound`.

До этого момента все «соединения» были self-loop (нода к себе через Tor/LAN).
Это первое настоящее peer-to-peer между двумя узлами.
