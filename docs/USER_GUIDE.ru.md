## 1. Архитектура и ключевые принципы

NeXXuS функционирует без центральных серверов, координаторов или облачных провайдеров:
- **Разбиение на 16 KiB чанки**: Любой файл нарезается на блоки фиксированного размера 16 384 байт.
- **Избыточность Reed-Solomon RS(4+2)**: Каждый блок кодируется в 6 шардов (4 информационных + 2 проверочных). Данные восстановимы при потере любых 2 из 6 узлов.
- **Шифрование XChaCha20-Poly1305**: Каждый чанк шифруется уникальным ключом файла. Пиры, хранящие шарды, видят только псевдослучайный шифротекст и не могут прочитать содержимое.
- **Транспорт Tor Onion v3**: Все P2P-соединения и адреса узлов по умолчанию маршрутизируются через сеть Tor в виде `.onion`-сервисов. Это гарантирует анонимность, скрывает физический IP-адрес и пробивает любые CGNAT и домашние фаерволы без проброса портов.
- **Proof-of-Retrievability (PoR)**: Математическое доказательство честного хранения шардов пиром за время < 3.0 секунд без передачи самого файла.

## 2. Быстрый старт и установка

### 2.1. Linux / Ubuntu / Debian

**Установка в одну команду (curl | bash):**
```bash
curl -fsSL https://raw.githubusercontent.com/PerfectFriend/NeXXus-Node/main/install.sh | bash
```

Скрипт автоматически:
1. Проверит системные требования (CPU, RAM, диск).
2. Настроит системный демон `nexxusd` в `/usr/local/bin/nexxusd`.
3. Создаст каталог данных `~/.nexxus` (хранилище CAS, логи, ключи).
4. Сгенерирует суверенную идентичность BIP-39 и Tor Onion v3 адрес.
5. Зарегистрирует и запустит службу systemd `nexxus-node.service`.

**Ручной запуск демона:**
```bash
nexxusd serve
```

### 2.2. Windows 10 / 11

1. Скачайте переносимый архив `nexxus-node_latest_windows_x64.zip` из релизов.
2. Распакуйте в удобную папку (например, `C:\NeXXuS`).
3. Запустите PowerShell от имени Администратора:
   ```powershell
   Set-ExecutionPolicy RemoteSigned -Scope Process
   .\scripts\windows\install-service.ps1
   ```
4. Демон зарегистрируется как служба Windows `NeXXuSNode` с автоматическим запуском при загрузке системы.

### 2.3. Android

**Через Termux (работа 24/7 с сохранением энергопотребления):**
```bash
curl -fsSL https://raw.githubusercontent.com/PerfectFriend/NeXXus-Node/main/scripts/install-android-termux.sh | bash
```
Скрипт активирует `termux-wake-lock`, предотвращая засыпание процессора при заблокированном экране, и настраивает автозапуск при перезагрузке телефона через `Termux:Boot`.

## 3. Конфигурация ноды (`node.conf`) и переменные окружения

И нода, и графический монитор читают конфигурацию из `~/.nexxus/node.conf` (или `$NEXXUS_CONFIG_DIR/node.conf`).

### Параметры `node.conf`:
```ini
listen=127.0.0.1:4001       # P2P-порт слушателя
api=127.0.0.1:4010          # Локальный WebSocket JSON-RPC порт
tor=1                       # Включение службы Tor Onion v3 (0 или 1)
threshold=3                 # Кворум аудиторов эпохи
epoch_secs=86400            # Длительность эпохи в секундах (24 часа)
auto_backup_hours=24        # Интервал автоматического резервного копирования
auto_backup_keep=5          # Глубина ротации бэкапов
por_enabled=1               # Включение периодических PoR-проверок
log_path=~/.nexxus/nexxusd.log
```

### Переменные окружения:
| Переменная | По умолчанию | Описание |
|---|---|---|
| `NEXXUS_LISTEN` | `127.0.0.1:4001` | P2P-интерфейс прослушивания |
| `NEXXUS_API_LISTEN` | `127.0.0.1:4010` | Локальный интерфейс WebSocket API |
| `NEXXUS_DATA_DIR` | `~/.nexxus` | Корневой каталог данных и хранилища `store.redb` |
| `NEXXUS_TOR` | `0` (или `1` в прод) | Интеграция Tor Onion v3 |
| `NEXXUS_API_ONION` | `0` | Публикация скрытого сервиса Onion для API (удаленный мониторинг) |
| `NEXXUS_MAX_STORE_BYTES` | `0` (безлимитно) | Дисковая квота хранилища (в байтах) |
| `NEXXUS_SYNC_INTERVAL_SECS`| `300` | Период автосканирования Sovereign Drive (0 = выкл) |

## 4. Суверенная идентичность и Seed Vault

NeXXuS использует стандарт BIP-39 (12 слов) для генерации криптографической идентичности:
- **Node ID**: SHA-256 от Ed25519 публичного ключа ноды.
- **Onion v3 адрес**: Выводится напрямую из Ed25519 ключа узла ($56\text{ символов base32} + \text{.onion}$).
- **Seed Vault**: Зашифрованный контейнер мнемоники (`AES-256-GCM`, PBKDF2 600 000 итераций). Plaintext-мнемоника никогда не сохраняется на диске в открытом виде.
- **Duress-PIN (PIN под принуждением)**: При вводе ложного PIN-кода нода открывает фиктивный профиль-приманку с нулевым балансом, не выдавая факт существования основного хранилища.

## 5. Sovereign Drive: Автоматическая синхронизация файлов

Папка `~/.nexxus/drive` представляет собой ваш защищенный суверенный диск:
1. Поместите любой файл или каталог в `~/.nexxus/drive`.
2. Демон в фоновом режиме обнаружит изменения, нарежет файлы на 16 KiB чанки, закодирует в Reed-Solomon RS(4+2) и зашифрует их.
3. Индекс соответствия сохраняется в локальной защищенной базе CAS.

**Управление через CLI:**
```bash
nexxusd sync                      # Ручной запуск синхронизации папки по умолчанию
nexxusd sync /path/to/my/folder   # Синхронизация пользовательского каталога
nexxusd sync status               # Статус: число синхронизированных файлов и объем
```

## 6. E2EE Мессенджер SMP и QR-контакты (ContactLink)

В протокол встроен протокол защищенного обмена сообщениями **Simple Messaging Protocol (SMP)** с маршрутизацией через сеть узлов без центрального сервера:

### Стандарт обмена контактами (Спецификация §7):
Контакты передаются в виде стандартного URI:
```text
nexxus://contact?addr=<NodeID_Hex64>&onion=<Tor_v3_Address>&name=<Alias>&fp=<Pubkey_Fingerprint>
```

- В Desktop UI: нажмите кнопку **«📷 Мой QR-контакт»**, чтобы показать QR-код собеседнику.
- Для добавления контакта вставьте URI в поле добавления или отсканируйте камерой.
- Все сообщения упаковываются в зашифрованные конверты X25519-ChaCha20-Poly1305 с совершенной прямой секретностью (PFS).

## 7. Восстановление данных из Mesh-сети (PROD-RESTORE-01)

В случае полной физической утраты устройства (поломка диска, кража):
1. Установите `nexxusd` на чистый компьютер.
2. Инициализируйте ноду вашей мнемоникой:
   ```bash
   nexxusd init --mnemonic="ваши двенадцать секретных слов из seed фразы"
   ```
3. Запустите процедуру дотягивания шардов из роя:
   ```bash
   nexxusd restore --from-mesh
   ```
4. Узел свяжется с пирами через Tor Onion v3, найдет распределенные шарды RS(4+2), проверит их хэши и восстановит целостность всех файлов вашего архива.

## 8. Режим хостинг-провайдера (Storage Provider CLI & UI)

Любой пользователь может монетизировать свободное дисковое пространство, предоставляя его в аренду участникам распределенной сети.

### Команды провайдера:
```bash
# Закрепить файл/CID для заказчика по цене 1000 nano-TON/MB на срок 60 эпох
nexxusd provider pin 0123456789abcdef... --price 1000 --duration 60

# Проверить статистику предоставленного пространства и активные сделки
nexxusd provider status

# Вывести подробный список всех закрепленных контрактов
nexxusd provider list
```

В мониторе `nexxus-desktop` панель **«🖥️ Хостинг-провайдер»** позволяет отслеживать доходность, объем занятого пространства и вручную управлять сделками в один клик.

## 9. Пост-квантовая защита (PQC) и ZK-SNARK PoR

- **FIPS 203 ML-KEM-768 ⊕ X25519 (Hybrid Shield)**: Сессионные ключи защищены гибридным алгоритмом, сочетающим классический эллиптический протокол Диффи-Хеллмана с решеточной криптографией Kyber. Это исключает угрозу ретроспективной расшифровки квантовыми компьютерами в будущем («Harvest Now, Decrypt Later»).
- **Succinct ZK-SNARK PoR**: Для подтверждения факта хранения терабайтов данных нода генерирует компактное 384-байтноe доказательство с нулевым разглашением. Проверка доказательства аудитором или смарт-контрактом блокчейна TON занимает менее 5 миллисекунд.

## 10. Полный справочник команд CLI (`nexxusd`)

| Команда | Описание | Пример |
|---|---|---|
| `nexxusd serve [store]` | Запуск фонового P2P-демона хранения | `nexxusd serve` |
| `nexxusd init [--mnemonic]`| Генерация новой идентичности или импорт сида | `nexxusd init` |
| `nexxusd id` | Просмотр Node ID, Ed25519 ключа и Onion-адреса | `nexxusd id` |
| `nexxusd status` | Состояние хранилища, NVMe квоты и здоровья | `nexxusd status` |
| `nexxusd peers` | Список подключенных P2P-пиров и задержки RTT | `nexxusd peers` |
| `nexxusd peer add <IP:PORT>`| Подключение к новому пиру вручную | `nexxusd peer add 192.168.1.10:4001` |
| `nexxusd upload <file>` | Нарезка файла на 16K чанки, RS(4+2) и заливка в сеть | `nexxusd upload backup.tar.gz` |
| `nexxusd download <root> <out>`| Скачивание и восстановление файла по Merkle Root | `nexxusd download a1b2c3... out.bin` |
| `nexxusd sync [path]` | Синхронизация папки Sovereign Drive | `nexxusd sync ~/.nexxus/drive` |
| `nexxusd provider pin <root>` | Закрепление данных в режиме хостинг-провайдера | `nexxusd provider pin <root> --price 500` |

| `nexxusd doctor` | Диагностика целостности базы данных и сети | `nexxusd doctor` |
| `nexxusd backup` | Создание зашифрованного атомарного бэкапа стора | `nexxusd backup` |
| `nexxusd restore` | Восстановление базы из резервной копии | `nexxusd restore candidate.redb` |
| `nexxusd update [--check]` | Проверка обновлений и бесшовный апгрейд бинарника | `nexxusd update` |

## 11. Графический монитор (Tauri Desktop App)

Десктопное приложение `nexxus-desktop` предоставляет визуальный контроль над всеми аспектами узла:
- **Обзор**: Состояние процесса-демона, аптайм, память, статус Tor и Telegram-оповещения.
- **Хранилище**: Браузер чанков, монитор Sovereign Drive, панель хостинг-провайдера, PoR-чекер.
- **Сеть & Пиры**: Таблица маршрутизации Kademlia, пинг узлов в реальном времени.
- **SMP Мессенджер**: Инбокс защищенных сообщений, генератор и сканер QR-кодов.
- **Безопасность**: Управление бэкапами, ротация ключей, настройка Duress-PIN.
